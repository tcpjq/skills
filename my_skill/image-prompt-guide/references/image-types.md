# 图片类型与表现媒介

分类以“这张图主要让人看什么”为准。**内容类型、表现媒介、使用用途是三个独立字段**：“头像”是用途，“人像”是内容，“水彩”是媒介；“海边婚纱人像”通常仍是人像。

## 内容分类

| 类型 | 识别线索 | 优先补齐的元素 | 当前支持 |
| --- | --- | --- | --- |
| 人像 / 人物 | 表情、身份造型、穿搭、人物动作是画面重点 | 人物、服饰、动作神态、场景、景别、光线、真实或造型质感 | 写实摄影有完整专篇；插画/3D 用通用框架 |
| 风景 / 自然 | 山海森林、天气季节、风景为主 | 地貌、季节天气、时间、前中后景、视点、色彩 | 通用引导 |
| 商品 / 静物 | 展示产品、器物、花束等 | 主体数量、材质、形态、摆放、背景、角度、光泽与阴影 | 通用引导 |
| 美食 / 饮品 | 菜品、食材、杯中饮料为主 | 食材与状态、器皿、摆盘、冷热感、俯侧角度、光线 | 通用引导 |
| 动物 / 生物 | 宠物、野生动物、幻想生物为主 | 物种外形、动作、栖息场景、毛发鳞片、视点、媒介 | 通用引导 |
| 建筑 / 空间 | 建筑、室内、空间布局为主 | 建筑或房间、材质、布局、透视、时间光线、人的尺度 | 通用引导 |
| 平面设计 / 信息图 | 海报、包装版式、图文信息是重点 | 用途、尺寸、信息层级、准确文字、图形、排版、留白 | 通用引导；不套“无文字”约束 |
| 抽象 / 综合场景 | 图案纹理、抽象概念、多元素叙事 | 主题、主次、形状材质、视觉秩序、色彩、媒介 | 通用引导 |

分类不是排他标签。人物拿香水：突出脸与人物故事→人像；突出瓶身、标签、材质→商品；两者都重要→选主类型，再补次类型元素。确实无法判断时只问：“这张图更想让人先看到人物，还是产品？”

## 媒介分类

- 写实摄影：照片式光影、空间、材质；可细分纪实、棚拍、时尚、电影剧照等。
- 插画 / 绘画：线条、笔触、上色、纸张等；水彩、油画、漫画是这里的选择。
- 3D / 数字渲染：造型比例、表面材质、灯光、渲染感觉。
- 平面 / 矢量：几何、色块、线宽、字体与版式。
- 混合媒介：明确各媒介作用范围，例如“摄影人物置于手绘背景”。

“写实”也可能指写实绘画，不能仅凭该词判断媒介。用户未指定时，可把媒介附在具体画面选项中，一次解决方向选择；已指定则直接沿用。

## 通用引导与成品

按已知内容填入：**主体及特征 → 动作或呈现状态 → 场景及空间关系 → 媒介与风格 → 构图视点 → 光色 → 关键材质细节 → 必要限制 → 比例**。只问当前最影响效果、而用户还没说明的元素。

例如“3D 猫坐在甜甜圈上，直接给”：识别动物主类型、3D 媒介，直接给出造型、支撑关系、材质、背景、灯光、构图，不询问人像年龄、脸型、摄影镜头。
