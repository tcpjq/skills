# 成品提示词的输出约定

## 默认交付

已展示设计表时，先按[选择合并规则](selection-table.md)锁定本次有效值：用户明确选择覆盖对应属性，未选项采用表中推荐。用户选择“不指定”的属性保持省略。展开设计后执行[场景合理性校验](scene-validation.md)；默认构图不成立时协调机位等关联项并说明必要取舍，不改用户锁定的人物与造型。不能因使用默认值就简化为选项列表。

先给可直接复制的中文提示词，放在一个文本代码块里。描述顺序为：

**主体与关键造型 → 场景 → 一个主动作与神态 → 景别、机位、构图 → 光线与色彩 → 风格、材质与细节 → 必要约束 → 画面比例（已定时）**。

默认交付**完整设计版**，把用户的重点放前面。可按人物造型、动作与空间、摄影表现、光色与质感分为3～6个自然段，仍是一条提示词。一般生活人像可写约300～500字，复杂运动或交互可进一步展开；信息集中且已经充分时也可以更短。这些只是篇幅参考，按实际设计需要增减，不凑字数。用户明确要精简或限字时遵循其要求，优先保留核心视觉关系。

“直接给”意味着省略问答，“只给提示词”意味着省略说明，两者都沿用所需设计深度；“提示词简短些、精简成一句、80字以内”等才是压缩篇幅的要求。“极简风格、简洁背景”描述画面，不自动压缩提示词。已有成稿且只要求润色时，尊重原有内容范围和篇幅，不强行扩写。

## 先定主风格、氛围与视觉层级

在当前创作记录中明确三项，不需要用户额外填写技术表：

- **主风格**：一个主方向，例如写实古装写真。自然表情、抓拍式动作、电影色彩可作为具体辅助表现，不必据此更换媒介或主类型。“写真+自然站姿”可以成立，不机械当作冲突；真正矛盾的是同时发生不了的姿势或互相抵消的效果。
- **核心氛围**：选一组简短主调，如“清雅静谧”，用配色、光线、表情和环境实现，不反复叠加同义气质词。用户已定冷色、强光或大笑时，不为了氛围改掉它们。
- **视觉层级**：主角与核心动作优先，其次是身份/风格的可见依据，背景提供空间和材质。通过光线、清晰范围、位置和细节分配建立主次，不把主角放大成不合理的真实体型，不把配角无依据地微缩，也不要求每处都同样锐利或显眼。

人物身份、时代、文化或其他抽象标签需要少量可见依据。把“通过衣料体现身份”改为具体的衣料与装饰；把“良好教养感”落实为用户认可的姿态或动作，不作为可见事实。身份不决定固定性格、肤色、体型或职业刻板外形。历史题材按[古装专项](portrait/historical-costume.md)核查依据程度，不能单靠一个现代造型词认证朝代。

## 成品中的设计信息

以下是设计覆盖检查，不是交给用户填写的表单，也不要求八类各写一段。按这张图实际可见与重要的内容展开：

| 设计方面 | 成品要具体到什么程度 |
| --- | --- |
| 人物与造型 | 先检查人数、性别、年龄、来源地区/文化背景、身份/场景角色五项，采用用户选择、展示的推荐或明确不限定；再设计可见服装。脸型、体型等按需，不由来源地区自动推导族裔、肤色或五官 |
| 场景与层次 | 说明主体在场景中哪个位置，前后景哪些元素帮助讲清地点；背景有主次，不是任意堆物品 |
| 动作瞬间 | 把动作名展开成一帧可见状态；关键手臂、躯干、双腿的关系与动作阶段一致。静态头像则展开表情与头肩姿态 |
| 表情与视线 | 抽象“专注、自信、开心”落实为目光目标、嘴角、眉眼等少量细节；不要求所有情绪动作同时出现 |
| 人物、道具与空间 | 说明接触、支撑、遮挡、距离或朝向中影响结果的关系；运动图交代关键器材和运动对象在哪里 |
| 构图与摄影 | 确定景别、拍摄方位、高度或俯仰、留白、对焦重点及清晰范围；用可见结果表达，不强行填焦距与米数 |
| 光色与质感 | 光源与方向有依据，明暗与冷暖服务画面；选能看见的皮肤、面料、金属、地面等材质反应。不要每张图都套“柔光+背景虚化” |
| 画面约束 | 围绕实际容易出错的部分选择：关键器材不裁掉、接触关系可信、单一瞬间等。保留用户所需人数与文字 |

每个扩写句应增加一个可以观察或取舍的画面决定。删去“杰作、极致高级、充满感染力”等不能落实为画面的重复形容。技术词与数值仅在帮助表达效果时使用；具体型号和参数并不天然增加质量。

八类信息是逻辑覆盖框架，不是固定八段，也不要求每一类独立写满。服饰、妆发不重要时可合并；复杂动作可占更大篇幅。环境材质优先描述能帮助主体成立的近景支撑与必要层次，不用更多背景细节冲淡主角。成品直接陈述可见画面，设计理由放在代码块外且仅按需要说明。

助手未定的候选值在成品前落实为明确选择，例如选“全身构图”和“绿色场地胶”，不把“全身或七分身”“地胶或木地板”留在同一成品里。用户要多方案时，每条各自明确；用户原文明确保留开放描述时尊重原文。

成品后可附“我补充了：……”，只列助手选定且用户未指定的重要细节，不把它们写成用户已确认。涉及惯用手、动作阶段、具体场地等重要创作选择时，也放在这行说明。可给一个最有用的调整方向；用户没有要求多方案时不连续输出大量变体。

用户要求“只给提示词”时，仅输出提示词正文，不加标题、说明、提问、调整建议或额外负面词。

## 可选内容

- **负面约束**：先找本画面实际风险，再选相关的少数项目；能用正向位置表达的优先具体写，例如“伞沿在额头上方，面部完整可见”。平台支持独立负面框时可单列；未知时用自然语言。“无现代元素”只适用于古代环境意图，“无奇幻光效”不能覆盖用户想要的仙侠风，“无文字”不能覆盖题字或菜单。手部、伞骨等约束只表达目标，不保证出图正确。
- **英文版**：用户要求或目标工具确有必要时提供；逐项保持中文语义，人物年龄、数量、左右动作与风格不能在翻译时漂移。
- **平台参数**：默认不写平台专属语法，不用未经核实的权重、模型版本、采样器、种子或 `--` 参数。画幅可用“3:4 竖构图”这种通用描述；确认平台支持后才转换为其参数。
- **设计说明**：用户问“为什么”或正在学习时解释 1～3 个关键决策，不能把教学内容混进最终提示词。

## 人像成品模板

使用模板前先通过[场景合理性校验](scene-validation.md)。关键对象在这个机位里不可见、被遮住或不在画框时，应调整方案；不能把两个视角的可见内容直接拼成一条写实单图提示词。近中景与大场景信息的取舍需反映在成品中。

```text
[风格/媒介]，[人物数量与已定特征]，穿着[可见服饰]，位于[场景及背景关系]，[一个主动作]，[表情及视线]。[景别]，[机位/方位]，[主体位置或构图]，[背景清晰程度]。[光源、方向与软硬]，[色彩与情绪]。保留[少量符合风格的皮肤、头发、衣料细节]，[与本画面相关的约束]。[已定画幅]。
```

模板是展开的顺序，不是每格只填一个词。填写时删除空项及方括号，不将模板原样交给用户。特写只写可见的领口、发型或首饰，不细写鞋款；站立全身交代脚部接地，骑行交代车座与踏板支撑，腾空动作交代双脚离地和地面投影，不能把“脚踩地面”当作所有全身图的默认值。多人需要说明相对位置和互动，不套“只有一人”。

## 交付前检查

| 检查 | 通过条件 |
| --- | --- |
| 忠于输入 | 用户明确给定的数量、年龄、服装、颜色、场景、媒介、动作和比例均被保留，或冲突已处理 |
| 人物基础完整 | 基础五项都有处理状态；未知项不能在选择阶段被漏掉，明确不限定的属性不回填；多人设定分别保留 |
| 类型匹配 | 插画不用“照片式肤质”作为硬约束；产品图不过分突出模特脸 |
| 单图可成立 | 场景连续，身体姿势和动作可同时发生，光照方向可以解释 |
| 构图可成立 | 景别和可见身体范围一致，焦点和观看重点一致 |
| 机位与视域 | 同一相机位置可看到指定内容；不看穿墙体或桌面，不把半身特写和完整大场景硬叠 |
| 尺度与层次 | 主体相对同层参照物的尺寸可信，前后高低不混用；近大远小有位置依据，非有意夸张时不微缩配角 |
| 设计已展开 | 适用的造型、动作、空间、构图、光影已经具体化，不只是复述用户短句加质量形容词 |
| 风格与依据 | 主风格明确、辅助表现兼容；时代或身份标签有可见支撑，创作改编不冒充严格复原 |
| 主次合理 | 描写深度集中在这张图的重点；全身运动图不执着于特写级毛孔，静态头像不加不可见鞋履 |
| 语言可用 | 没有备选清单、模板占位符、互相抵消的风格或无意义强化词 |
| 约束适量 | 约束与当前失败风险有关，不覆盖用户要求的文字或多人 |

提示词只能表达意图。没有真实出图样本时，可评估文字的完整性、选择保留、内部一致和可见关系，不能由此宣称“稳定出图”、捏造出图成功率或给貌似客观的图像效果分数。用户希望验证效果时，在得到实际样本后按主体保留、动作、风格识别和结构偏差比较；尽量保持工具、模型、画幅及其他条件一致，每轮优先只改一个待验证因素，不自动调用出图工具。不要宣称“保证五指正确”“人物永远一致”。
