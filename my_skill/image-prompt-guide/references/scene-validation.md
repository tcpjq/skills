# 场景合理性校验

每次交付提示词前执行。简单头像快速检查即可；多人、高低分层、强透视、人物与大型物体互动时，先画清空间草图再写最终构图。校验是对文字方案的审查，不能代替对实际生成图的检查，也不保证模型执行正确。

写实单场景检查单一机位；多视图图解、信息图、拼贴和非写实创作按用户指定的版式、比例与叙事关系校验，不强迫所有作品服从一台物理相机。

## 先建立一个能成立的场景

在创作记录内用几行说明，不要求用户填写，也不把过程整段塞入成品：

| 要素 | 需要说明 |
| --- | --- |
| 实体与支撑面 | 谁站在哪里，桌、椅、车、地面、桥面或城墙分别在哪里；谁接触或支撑谁 |
| 相机 | 在主体哪一侧，相对人物与地面的高度，朝哪个方向看；高度与俯仰分别判断 |
| 相对位置 | 哪些实体更近/更远、更高/更低；画面上下不是世界的高低或前后 |
| 视线与遮挡 | 从此机位能否看见脸、动作和目标对象；墙、桌面、衣物等遮住什么 |
| 画幅与尺度 | 景别、可见身体范围、同层尺寸参照；相同真实身高的人在不同距离应有何种投影关系 |

如果尚不能用一套位置关系解释全部要求，不先堆光线、衣服或镜头参数掩盖问题。

## 逐项检查

| 检查 | 需要通过的条件 | 常见错误 |
| --- | --- | --- |
| 单一视点 | 写实连续场景可由同一相机方向和取景解释 | 把正面近景头像与另一俯视军阵图上下拼接，却声称单张写实照片 |
| 视域 | 所需实体落在这个机位的视野与画框内 | 近距离向上拍墙顶面部，又要求完整看见墙脚道路 |
| 遮挡 | 墙体、栏杆、桌面和人物前后关系一致 | 镜头看穿城墙或桌面；书、伞面明明挡住脸却要求脸全部可见 |
| 尺度 | 人与同层建筑、家具、器材的比例可信；远近导致的大小变化有依据 | 皇帝按半身大像画，城门却像他的腰带；近处正常士兵被写成微缩模型 |
| 主次 | 通过清晰度、光线、色彩、位置和细节安排突出主体 | 把“主角最重要”执行成主角真实体型更大，配角物理变小 |
| 动作与接触 | 同一瞬间的关节、支撑、握持与重心可协调 | 跳跃时脚踩地，靠椅背却没有椅背，持物手同时做互斥动作 |
| 注意力与表情 | 人物的头部和目光指向指定目标，面部可见范围支持所写神态 | 看城下却直视镜头；远景小人物要求看清眼神、毛孔和微表情 |
| 光影与动态 | 主光、投影、反射及风向互相协调 | 相同风吹出相反衣发方向；接触阴影让悬空物体看起来落地 |

写实任务默认使用正常的实体尺度；用户明确要求巨人、微缩景观、强制透视、拼贴或超现实构图时，按其艺术目标校验，不自动“纠正”为普通比例。

## 尺度判断不要只看画面占比

- 近景/远景描述与相机的距离，城上/城下描述与建筑的高度关系；二者不能互相代替。“画面下缘”也不自动等于前景。
- 相同真实尺寸、相近姿态的实体通常近大远小。近处士兵应如何呈现，取决于他们是否确实比城墙上的人物更靠近镜头，不能因其是配角就随意缩小。
- 半身裁切与完整全身不能直接用图中高度判断真实身高。先看人与各自所在平面的城垛、门洞、地砖或其他人的关系，再判断是否出现巨人/微缩错觉。
- 相机很近时人物显大本身可以合理；缺乏前后层次和建筑参照、把不兼容机位合成一张，才是优先排查的问题。没有图片时不要确认具体哪项已经发生。
- 焦距词、画质词、虚化词和“比例正确”不能代替位置设计。相机位置、距离、取景与遮挡仍须自洽，不承诺只改“长焦”就修复。

摄影中的尺度感受与相对距离、参照物和透视安排有关，可参考[Adobe Lightroom Academy：Reference for Scale](https://lightroom.adobe.com/academy/principles/composition/scale-reference)。[Nikon 镜头说明](https://www.nikonusa.com/fileuploads/pdfs/Nikkor%20lens%20Broch_061017.pdf)也说明了拍摄距离对透视关系的影响。

## 未通过时怎么处理

1. 保留用户明确的人物、身份、时代、颜色、动作与叙事目标；先修正助手补充的机位、景别、远近标签和不必要细节。
2. 一旦调整机位，连带复查可见范围、遮挡、前后景、对焦范围和尺度参照，不保留旧镜头里的不相容细节。
3. 两个明确要求确实争用画幅或视角时，只问一次取舍。用户已交给助手决定或要求直接给时，选择更贴合核心目标的一套自洽方案；必要时简短说明取舍，不擅自输出拼贴或多分镜。
4. 校验通过后，将必要位置关系写进成品，删掉相互拉扯的旧句。校验项不是负面词清单，不能只追加“不巨人、比例正确、真实透视”而保留矛盾布局。
5. 默认直接交付；用户要求校验、反馈具体问题或构图需要重要取舍时，可附1～3句文字校验结果，不输出冗长推理。用户只要提示词时仍只交付正文。

## 皇帝目送军队：三种独立构图

已定的故事：皇帝站在墙顶俯看城下出征将士，神态自豪。以下是互不混用的构图方向，不是三幅拼贴；推荐根据用户观看重点选择。

| 方向 | 相机与可见内容 | 必须接受的取舍 |
| --- | --- | --- |
| 正面神态优先 | 机位在城墙外侧、接近人物面部高度，镜头朝向皇帝；正面近中景，城垛交代站位，目光朝镜头下方的城外 | 将士位于画外，不硬塞微型队伍到下缘；皇帝相对身边城垛保持正常尺度 |
| 同框空间优先 | 相机从城外斜正前方退远并升高，宽景向下兼顾墙顶、墙面与城外道路；军队沿道路离城 | 皇帝占比随景别降低，表情只能适度辨认，不要求眼神特写与微表情精度 |
| 军队出征优先 | 相机在城外道路上与城墙保持距离，将士向镜头方向行进，墙顶皇帝在较远处 | 近处将士相对更大，皇帝较小；不同时给皇帝半身近景 |

选择正面神态优先时，城垛可在该画面中到人物腰胸附近，作为具体场景的比例参照；这不是对所有历史城墙尺寸的统一规定。不为了增强皇帝威严把他的身体放大，也不让相机透过墙体看见完整道路。

## 有图与无图的反馈边界

有生成图时先检查实际出现的人墙比例、前后层次、遮挡、肢体和视线，再定位需改的文字；有实际工具或模型设置时一并考虑。用户只描述问题而未提供图片时，给基于文本的可能原因与修正方案，不能声称已经观察到图像细节或验证修复成功。实际样本仍按[输出约定](output-contract.md)中的方式比较。
