# 人像术语：看见差异，再决定用词

这里服务于“这是什么意思 / 我怎么选 / 给我看看”。先查对应小组，不把整表发给用户。**每次解释采用：一句通俗意思 → 两个可见效果 → 一条能复制的短句 → 查看入口。** 专业名词是表达工具，用户选效果就够了。

## 图解入口

离线页：[打开人像术语对照](../../assets/portrait-terms.html)。实际向用户输出链接时，把相对路径替换为当前技能所在目录的绝对路径；不要写死本机用户名。可加以下锚点：

| 用户想看 | HTML锚点 | 看什么差异 |
| --- | --- | --- |
| 脸特写、半身、全身 | `#framing` | 同一人物在画面中占多少 |
| 平视、俯拍、仰拍 | `#camera-angle` | 相机与人物的观看关系 |
| 居中、三分法、留白 | `#composition` | 人物放哪里，空白留在哪 |
| 环境清楚还是模糊 | `#depth-of-field` | 背景细节是否可辨 |
| 柔光与硬光 | `#light-quality` | 阴影边缘柔还是硬 |
| 正面、侧光、逆光 | `#light-direction` | 光从哪里来，脸部亮暗如何 |

## 景别、视点与构图

| 术语 | 通俗解释 / 选择依据 | 可复制短句 | 易混点 |
| --- | --- | --- | --- |
| 面部特写 / close-up | 主要看五官和表情，环境很少 | 面部特写，眼神和细微表情为重点 | 不同时要求完整鞋履 |
| 胸像 / bust portrait | 拍到胸部附近，保留肩颈 | 胸像构图，双肩自然放松 | 不保证手完整入镜 |
| 半身 / half-length | 通常拍到腰部附近，兼顾表情与上身动作 | 腰部以上半身构图，手中书本完整可见 | 用明确裁切部位解决不同理解 |
| 七分身 / three-quarter length | 约拍到膝部附近，展示大部分穿搭 | 画面拍到膝部附近，避免在关节处生硬裁切 | 不是精确占全身70% |
| 全身 / full-length | 从头到脚完整呈现 | 全身完整入镜，保留与动作相符的接地、骑乘支撑或腾空关系 | 人物大小与背景范围仍需另定；全身不等于必须站在地上 |
| 环境人像 / environmental portrait | 人与场所共同讲故事 | 人物与书店环境共同呈现，保留书架层次 | 不等于远景，也不必完全锐利 |
| 平视 / eye-level | 镜头接近眼睛高度，观看关系平等自然 | 接近人物眼睛高度的平视拍摄 | 不是要求人物必须直视镜头 |
| 俯拍 / high-angle | 从较高处朝下看 | 相机略高于人物眼睛，轻微向下拍摄 | 高机位也可水平拍，两者不完全等同 |
| 仰拍 / low-angle | 从较低处朝上看，强调高度 | 低机位轻微仰拍，保持自然身体比例 | 极端角度可能强调透视变化 |
| 三分法 / rule of thirds | 把画面想成九宫格，主体靠近三分线 | 人物位于画面右侧三分之一处 | 只是位置参考，不是必须精确对齐 |
| 居中 / centered composition | 视觉重点稳定在中间 | 人物居中，左右空间平衡 | 居中不等于背景必须对称 |
| 负空间 / negative space | 留下安静区域，让人物更突出或供排版 | 人物偏右，左侧保留干净留白 | 要排文字时不要同时写“无文字” |
| 框架构图 / framing | 用门窗、树枝等围出观看入口 | 透过门框看向人物，门框不遮挡脸部 | 与图像外边框不是一回事 |
| 引导线 / leading lines | 走廊或道路的线把视线带向人物 | 走廊线条引向远处人物 | 先保证环境中确实有对应线条 |

## 清晰范围与镜头语言

| 术语 | 通俗解释 / 选择依据 | 可复制短句 | 易混点 |
| --- | --- | --- | --- |
| 景深 / depth of field | 对焦点前后看起来清楚的空间范围 | 人物与身旁物品处于清晰范围 | 不是照片整体分辨率 |
| 浅景深 / shallow depth of field | 清楚的前后范围较窄，常用于突出主体 | 眼睛清晰，身后背景自然虚化 | 不是“整张图模糊”；背景虚化还受背景位置影响 |
| 深景深 / deep depth of field | 更多前后层次保持可辨 | 人物与近处环境共同清晰 | 不代表所有距离绝对一样锐利 |
| 散景 / bokeh | 焦外模糊区域呈现的外观，如柔和光斑 | 背景灯光形成柔和焦外光斑 | 不等于所有模糊，更不是运动拖影 |
| 对焦 / focus | 决定哪里优先清楚 | 对焦在靠近镜头的一只眼睛 | “人物与环境都清楚”是范围需求，不能只靠改对焦点 |
| 运动模糊 / motion blur | 曝光期间运动留下拖动感 | 人物面部清楚，移动的裙摆有轻微动态模糊 | 与失焦模糊不同；真实照片不必自带模糊 |
| 35mm视角 | 以全画幅等效为参照的偏广视角，可带入环境 | 偏广视角的环境人像，人物不过分靠近镜头 | 不等于自动拍全身；数值可省略 |
| 50mm视角 | 以全画幅等效为参照的常见标准视角 | 自然观看距离的人像，人物和环境比例协调 | 不保证与人眼完全相同 |
| 85mm视角 | 以全画幅等效为参照的中长焦视角，常用于突出人物 | 中长焦人像感，人物突出，背景简洁 | 85mm是焦距，不是机位角度；也不必然只适合半身 |
| 大光圈 / wide aperture | 在其他条件相近时，较小f数意味着较大开口，常使景深变浅 | 人物清楚，背景柔化 | 不必在提示词中填写f值；不能单靠f值保证虚化 |
| 透视 / perspective | 近远物体在画面中的相对大小关系 | 自然拍摄距离，面部与身体比例协调 | 相机位置直接影响透视；焦距与取景距离常一起变化，不能说换焦距就必然改脸型 |

焦距影响视角与取景范围；景深还与光圈、拍摄距离等相关。用上述数值只是提供视觉意图，AI未必按真实镜头精确执行。参见[Nikon 焦距说明](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/understanding-focal-length)及[景深与光圈](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/understanding-maximum-aperture)。

## 光线与色彩

| 术语 | 通俗解释 / 选择依据 | 可复制短句 | 易混点 |
| --- | --- | --- | --- |
| 柔光 / soft light | 阴影边界过渡柔和，通常更平缓 | 窗帘散射的柔和窗光，阴影过渡自然 | 不等于高亮、低反差或暖色；仍可有方向 |
| 硬光 / hard light | 阴影边缘清楚，光影形状明显 | 直射阳光形成清晰阴影边缘 | 不等于暗画面或不真实 |
| 正面光 / front light | 光主要从镜头附近照向人脸 | 柔和正面光，面部亮度均匀 | 仍可能有鼻下等局部阴影 |
| 侧光 / side light | 主要从人物一侧照来，强调体积 | 画面左侧窗光照亮一侧脸颊 | 写清画面左右或人物左右，避免歧义 |
| 逆光 / backlight | 光在主体后方，轮廓更突出 | 背后阳光勾勒头发边缘，面部有柔和补光 | 无补光时脸可能较暗；不是必然剪影 |
| 轮廓光 / rim light | 主体边缘出现亮线，帮助与背景分离 | 头发和肩部边缘有细微轮廓光 | 不等于整个人发光 |
| 伦勃朗光 / Rembrandt lighting | 侧上方主光，在暗侧眼下脸颊留下小三角亮区 | 侧上方主光，暗侧脸颊保留小块三角亮区 | 不是所有45°侧光；三角形取决于脸与光的关系 |
| 蝴蝶光 / butterfly lighting | 正前上方主光，鼻下形成小蝶形阴影 | 正前上方柔光，鼻下保留小块对称阴影 | 不是蝴蝶形光斑或装饰 |
| 高调 / high-key | 画面整体偏亮、暗部较少 | 明亮背景与轻柔阴影，整体高调人像 | 不等于过曝或丢失所有细节 |
| 低调 / low-key | 画面暗部较多，用局部亮面建立重点 | 深暗背景，侧光只照亮面部重点 | 不等于欠曝、全黑或硬光 |
| 黄金时刻 / golden hour | 日出后或日落前一段偏暖低角度光照时段 | 日落前低角度暖阳，温暖自然 | 时长随地点季节变化，不写死一分钟或时刻 |
| 蓝调时刻 / blue hour | 日出前或日落后的蓝色暮光时段 | 日落后蓝色暮光，城市灯光逐渐亮起 | 不是深夜，也不固定长一小时 |
| 色温 / color temperature | 描述照明光色的概念；成片冷暖还受白平衡影响 | 整体冷蓝色调，肤色自然 | 摄影灯低K通常偏暖、高K偏冷；白平衡K设置的影响不能照搬成光源K |
| 饱和度 / saturation | 颜色看起来鲜艳还是克制 | 低饱和度配色，保留自然肤色 | 低饱和不等于变灰、低亮度或黑白 |
| 莫兰迪色 | 常用来表达柔和、偏灰、克制的配色倾向 | 灰蓝与灰米色的低饱和配色 | 不是标准色温值；给具体颜色更明确 |

柔硬光以阴影边缘和光源相对大小等因素理解，参见[Adobe 柔硬光说明](https://www.adobe.com/creativecloud/photography/technique/diffused-light.html)。经典人像布光的辨识特征见[Profoto 伦勃朗光教学](https://www.profoto.com/bg/en/still-photography/tips-tricks/how-to-create-rembrandt-light/)及[伦勃朗光与蝴蝶光实例](https://www.profoto.com/nl/en/still-photography/profoto-stories/character-portraits-with-john-russo-and-profoto-d2)。

## 风格与质感

| 术语 | 通俗解释 / 选择依据 | 可复制短句 | 易混点 |
| --- | --- | --- | --- |
| 纪实感 | 像真实发生的一刻，姿态与环境有生活逻辑 | 自然抓拍瞬间，动作不刻意，环境有合理生活痕迹 | 不要求画面脏乱、低清或人物疲惫 |
| 电影感 | 对光色、情绪与场景叙事的组合描述 | 冷色雨夜与局部暖光对照，人物安静等待 | 没有统一参数；不必加黑边、宽画幅或特定胶片 |
| 胶片感 | 可选择颗粒、色彩响应、柔和高光等感觉 | 细腻颗粒，色彩克制，高光柔和 | 不必同时褪色、划痕、漏光和模糊 |
| 自然肤质 | 皮肤具有合理纹理与明暗，保留个人特征 | 自然皮肤纹理，适度修饰，肤色真实 | 不等于必须新增雀斑、痘痘或夸张毛孔 |
| 材质垂坠 | 布料受重力与姿势影响形成自然形态 | 亚麻衬衫有细微褶皱，袖口自然垂落 | 不同面料不能都写成同一光泽和褶皱 |

## 一个解释示范

用户：“浅景深是不是更高级？”

回答：“它只是让清楚的前后范围更窄，常能突出人。要看表情，可以选‘眼睛清晰，远处背景柔和模糊’；要讲书店里的故事，可以选‘人物和身旁书架都清楚’。两种都适合人像，取决于你想让人看哪里。”随后按需要提供图解入口，不评价某种效果天然更高级。
