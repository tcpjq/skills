# 写实人物摄影元素库

供 image-prompt-guide 按需检索、组合和转述。来源是用户提供的《AI 写实人物摄影提示词分类表》；原稿宣称 74 个维度，逐行核对后实际为 10 个模块、87 条细分类别。以下完整保留原类别及原可选内容，并在使用说明中澄清概念。

87 是保留原资料的分类行数，其中存在交叉、包含和重复，不代表 87 个独立参数，也不是必填项目。先提炼少量关键要点作为创作记录，再按画面需要展开动作、空间、构图与光影；要点数量不限制成品的设计深度。优先选用户明确要求及影响画面的要素，不为凑数堆叠术语。

引导问题用于把用户的日常描述映射到合适元素，不是一次性展示给新手的完整问卷。读取相关模块即可，已知信息直接复用；只有缺失信息会明显改变结果时才追问。原可选内容不是封闭菜单，可接受用户自己的描述。多数行允许兼容组合，互斥选择与重复表达由使用说明判断。

稳定 ID 采用 P模块号.模块内序号，便于在需求记录和示例中引用。生成提示词时转成自然语言，不把 ID 或整张清单塞进输出。头部、躯干、眼睛、相机的方向须明确参照系；真实感遵从场景、光线、材质及可见尺度，不默认添加瑕疵、噪点或模糊。

| P02.09 | 五官特征 | 哪些眼、鼻、唇等五官特征最重要？ | 大眼睛、细长眼、单眼皮、双眼皮、高鼻梁、挺鼻、薄唇、丰满嘴唇、自然五官 | 术语：五官、眼型、眼睑、鼻形、唇形。按部位少量组合；高鼻梁与挺鼻有重叠，自然五官较宽泛，优先保留明确特征。 |
| P02.10 | 身材特征 | 身高感、体型和身体比例希望怎样？ | 高挑、娇小、纤细、匀称、健美、丰满、修长双腿、明显腰线、自然身体比例 | 术语：体型、身体比例。高挑与纤细可并存；宽泛形容词按需要选择，不把一种体型当作真实或自然的唯一标准。 |

| P02.12 | 人物气质 | 人物给人的长期气质是什么？ | 温柔、知性、清冷、甜美、活泼、成熟、干练、优雅、文静、自信、慵懒 | 术语：人物气质。与 P06.02 的当下情绪区分；选一两个主要词，必要时用表情、姿态、服装支持，避免堆叠相互牵制的形容词。 |
