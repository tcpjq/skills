# 给没有方向的用户的六种人像方案

这些是助手建议，只有用户选择后才成为已定条件。每次推荐2～3种足够；也允许用户混搭或自行描述。人物性别、年龄、外形与数量沿用用户，下列单人例子的成年女性只是示例角色。

| 方案 | 用户能想象的效果 | 关键设计 | 最值得让用户选的一个旋钮 |
| --- | --- | --- | --- |
| 窗边日常 | 安静、自然，像生活中拍到的一刻 | 半身、窗光、简单动作、背景略柔化 | 看镜头还是专注手中物品 |
| 街头时尚 | 更重穿搭和姿态，城市参与构图 | 全身、简洁街景、行走或停步、服装纹理 | 完整穿搭还是表情特写 |
| 自然户外 | 清爽舒展，有风和植物层次 | 公园/海边、自然光、人与环境关系 | 环境多一点还是人物突出 |
| 职业头像 | 清楚、友好、适合个人介绍 | 胸像、简洁背景、面部均匀柔光 | 亲切自然还是正式沉稳 |
| 电影夜景 | 有故事，冷暖或亮暗形成情绪 | 雨夜/路灯、明确主光、安静动作 | 明亮可见还是暗部更多 |
| 环境纪实 | 先看到一个人在做什么，再看到场所 | 真实工作或日常场景、环境可辨、自然姿态 | 活动瞬间还是静态肖像 |

## 可改写的示例成品

### 窗边日常

自然生活人像摄影，一位成年女性坐在窗边，穿浅蓝色棉质衬衫，双手自然捧着一本展开的书，目光落在书页上，神情放松。腰部以上半身构图，接近眼睛高度的平视视角，背景可辨认出书架但轻微虚化。柔和侧窗光照亮面部，整体自然温暖，保留适度皮肤纹理与衣料褶皱，单一连续场景。

### 街头时尚

街头时尚人像摄影，一位成年女性穿深灰色西装外套、直筒长裤和黑色鞋履，在简洁的城市街角自然停步，一只手轻扶衣襟，视线看向画面外。全身完整入镜，双脚自然落地，人物位于右侧三分之一处。明亮阴天的柔和自然光，色彩克制，衣料材质与身体比例真实，背景街景保留少量层次。

### 自然户外

自然户外人像摄影，一位成年女性穿米白色亚麻连衣裙，站在海边步道上，身体朝向海面，头部轻轻转向镜头，表情平静。全身构图，人物周围保留海面与远处地平线。日落前暖阳从侧后方勾勒头发轮廓，面部有自然的柔和亮度，海风轻轻带动裙摆，肤色与布料质感自然。

### 职业头像

写实职业头像摄影，一位成年女性穿深蓝色简洁上衣，双肩放松，微笑看向镜头。胸像构图，人物居中，背景为干净的浅灰蓝色。柔和正面主光配合轻微侧向明暗变化，面部清晰，肤色自然，头发整洁并保留细微发丝，适度修饰而不过分磨皮。

### 电影夜景

电影感写实人像，一位成年女性身穿红色雨衣，在夜雨中的公交站静静等车，目光看向道路远处，站姿自然。全身完整入镜，站台顶棚与湿润路面建立连续空间。冷蓝色环境光中，站牌附近的灯光照亮面部一侧，雨衣表面有自然雨滴与反射，背景灯光轻微虚化，人物和站台是画面重点。

### 环境纪实

纪实环境人像，一位成年女性坐在陶艺工作台前，双手共同塑造同一件湿润陶坯，低头专注于手中的工作。平视中景，人物、双手和陶坯清楚可见，背景工具架保留可辨细节。侧窗自然光照亮工作台，衣袖和台面有合理使用痕迹，材质与遮挡关系真实，画面呈现一个自然工作的瞬间。

这些示例不自动附加固定画幅、镜头数值、单人排他约束或无文字要求。用户用途明确时再补；用户指定老人、男性、双人等时，按其设定改写全部相关关系。
