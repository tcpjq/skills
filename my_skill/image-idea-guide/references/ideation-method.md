# 如何从主题得到有区别的画面

## 先判断用户缺的是哪一层

| 输入 | 当前缺口 | 第一轮应该给什么 |
| --- | --- | --- |
| 可爱壁纸、夏天、孤独、自由 | 情绪或主题还没有画面 | 主体、场景、动作、媒介已经组合好的多种方向 |
| 将军应敌、女孩旅行 | 有角色或动作，还缺叙事与视觉方向 | 不同环境、动作时刻、人物关系和表现方式 |
| 想画3D猫咪壁纸 | 主体媒介确定，场景未定 | 全部保留3D猫，变化世界设定、动作与构图 |
| 完整场景，想换上衣颜色 | 已到设计细化 | 直接修改或使用具体提示词技能，不重启创意菜单 |

不用首先问发色、年龄、镜头、具体朝代或设备尺寸。已有明确条件记下来，其余先设计可替换的候选。无法区分抽象词含义时，也可用两三种视觉理解做选项，而不是连续追问。

## 每个方案的创意配方

**主题 + 主体 + 场景 + 一个正在发生的事 + 视觉亮点 + 媒介/风格 + 情绪/构图用途。**

例如“可爱”可以是“小水母在气泡里递送星光信件，透明蓝绿的水彩海底，角落留出安静水域”；“夏天”可以是“无人泳池旁的冰饮与水纹，近景写实静物”。不要求所有画面都有人物或复杂故事。

创意亮点可来自大小变化、意料之外的功能、熟悉物件换环境、角色关系、光影时刻或视角。例如云朵当枕头、莲蓬当小船、将军与敌骑隔着雨幕对峙。需要保持真实的任务不自动加入幻想；用户要求幻想时，不套普通尺寸去消灭创意。

## 候选的差异检查

每组与其他组至少在下列两项上有所不同，用户锁定的属性不参与强行变化：

- 场景或世界：田野、海边、雨夜街道、微缩厨房、架空天空。
- 主体或关系：单个角色、伙伴互动、无人静物、环境为主。
- 动作阶段或故事：等待、奔跑、发现、对峙、护送，而不是同一姿势换衣服。
- 媒介与视觉：手绘动画、黏土定格感、像素、纸雕、摄影、3D。
- 构图与情绪：大留白壁纸、近景细节、宽景叙事、俏皮温暖或紧张肃穆。

先内部产生更多草案，再保留最有差别的约5个。不要为“多样”违反用户的猫咪、无人、写实、非暴力等限制。自然可行方向与大胆幻想可同时展示，但要让用户看清区别。

## 创意比较表

| 列 | 内容 |
| --- | --- |
| 编号与创意名 | A、B等稳定编号；名称让用户记得画面，不只是风格标签 |
| 完整画面 | 谁在哪里做什么，以及画面最特别的地方，通常一两句 |
| 角色与媒介/风格参考 | 原创角色或用户指定角色，媒介与具体可见表现；有命名参考则点明借鉴范围 |
| 构图或用途亮点 | 为什么适合壁纸、故事插画、情绪表达或当前需求；不要用成功率推荐 |

推荐一个方案，理由基于主题、用途和信息表达，不说“最稳定”“保证最好看”。通常推荐大众容易想象且有明确亮点的方向，再留其他有区别的选择。

## 点名风格、作品、典故怎么用

允许保留和推荐艺术家风格、作品氛围与角色参考，同时写出画面效果。比如“宫崎骏式手绘动画氛围”可配水彩质感乡野、饱满云层、清亮日光和自然风感，不能只在同一段前面换一个艺术家名字。

有可靠、适配的参考关联时，首轮至少一案主动点名并解释借鉴点，不要全部停留在“动画感、电影感”等泛称。例如夏日乡野可联想宫崎骏式动画氛围，将军对阵可联想《三国演义》，可爱壁纸可包含熟悉卡通形象；其余方案保留原创探索。用户明确不想引用艺术家或作品时不添加，没有把握的关联不用编造。原创场景或原创角色仍可搭配用户愿意采用的风格参考，不能把“原创场景”误读为禁止一切风格联想。

分清三类：

1. **风格联想**：借鉴自然场景、光色、动作或情绪。原创男孩田野奔跑是新构思，不因此变成《龙猫》的真实镜头。
2. **原作角色或情节**：用户想看具体角色或事件时，保留其选择；不熟悉的细节先核查。不要把原创人物擅自改成知名角色。
3. **改编或架空**：把典故人物放入新场景、新媒介或新关系时，说明是改编。文学故事不能作为史实保证；跨时代混搭若是用户意图就明确作为创作设定。

创意发散本身不依赖联网。需要作品出处、具体事件、精确时代或真实参考图时，才查原作或官方资料，链接只支持对应事实，不宣称官方创作者认可本次构思。

## 按用途提前做一点设计

- 壁纸：考虑留白、图标或时间的可读区域、主体不挤边。设备未知时先给可调整的留白方向，不锁定像素尺寸或9:16。
- 故事画面：选一个清楚的瞬间与主次，不把连续剧情全部放进同一张图。
- 多人或战争：先定主将、对手与群像的层级，人物重要不代表物理更大；近景表情与大军全貌需合理取舍。
- 商业或平面：文字、品牌、留白按用户要求处理，不默认添加或排除标题。
