# 选择、混搭与成品衔接

## 对话内保留的内容

维护主题与用途、用户硬性要求、本轮编号表、推荐编号、已选方案、用户改动和排除项。编号属于当前表，不是永久主题编号；换一批后以最新表为准。用户引用旧编号或创意名时能唯一确定就沿用，无法确定才问一句。

| 用户回复 | 执行动作 |
| --- | --- |
| A、选2、我喜欢水母邮差 | 锁定对应方案；默认直接展开该方案提示词，不继续展示其他候选 |
| 生成、继续、都按推荐、你决定 | 采用当前明确推荐的编号，展开；若还没有候选表且用户明确让助手决定，先内部选一套完成 |
| A，但把猫换成小兔 | 只替换角色和必然受影响的动作，保留A的场景、风格与用途 |
| A的场景+B的角色+C的画风 | 按字段合并成一个画面，检查比例、动作、媒介是否协调 |
| 再来几个、更多、不要小动物 | 保留主题和新排除项，换真正的新构思，不只换颜色 |
| 喜欢A，但先别写提示词 | 留在创意讨论，可给A的变化方向，不立即交付成品 |
| 这是什么风格，能看看吗 | 解释或提供可用的查看方式，不把问题当作提交选择 |
| 没有新消息 | 保持待选，不自动认定用户接受推荐 |

不明确的“A+B”通常可先理解为想混搭，若不知道取哪部分会明显改变画面，只问一次“更想保留A的场景还是角色”。用户明确交给助手决定时，选一套相容组合并说明。

## 锁定创意简报

选定或混搭后，内部整理这些字段；用户只要成品时不额外展示整表：

```text
主题与用途：
选定方案与改动：
核心画面：谁/什么，在何处，正在发生什么
主体与角色关系：无人也可以；已有年龄、性别等原样保留
媒介与主风格：
参考与借鉴范围：艺术家风格、原作角色/情节、原创或改编
主氛围与光色：
构图重点与留白：
用户明确条件：
方案建议的默认细节：
排除项与待核实内容：
```

选择某方案意味着接受该方案已展示的画面设定，不意味着可以任意增加新角色、转成另一媒介或把原创主题替换为知名角色。人物方向未明确的属性只作协调补充或不限定，不从用户语言推断身份。

## 与 image-prompt-guide 衔接

同伴技能可用时读取其 SKILL.md。在本仓库相邻目录通常为 `../image-prompt-guide/SKILL.md`，实际以当前安装位置为准；它是可选增强，不能当硬性依赖。

传递创意简报，并明确：**用户已经选定这一方案，按其要求直接展开；沿用确定的角色、场景、动作、媒介、用途与参考，不重新发散，不重问已有条件。** 可以采用其完整设计、人物基础检查、历史依据与场景合理性校验流程。

用户明确想亲自选更多细节时，才展示针对当前方案的可选表；已定媒介和场景不再当未知项。默认不把新技能首轮选择接成另一轮漫长问卷。

## 单独安装时也能完成

未发现同伴技能或当前环境无法调用时，直接完成以下工作，无需安装依赖或停止：

1. 保留简报中的明确条件，把一个画面写完整：主体、动作、场景层次、媒介与可见风格、构图、光色、材质、必要约束。
2. 一般可按3～6个自然段组织，约200～500字或按需要增减；用户要求限字就遵循，不为模板凑字。
3. 用少量具体细节体现所选风格和故事，不能只复述主题加“高级、精美、8K”。
4. 检查同一时刻、角色支撑/接触、近远大小与遮挡、风向光影；写实场景使用一个可解释的机位。超现实和纸雕等按其创作规则保持视觉逻辑，不一律要求真实比例。
5. 历史/作品参考未核实时写清借鉴范围，不给未验证的故事或服化道冠以准确复原；不因篇幅丰富宣称稳定出图。

## 成品输出

用户未指定格式时给一条可复制中文提示词，可用一个文本代码块；块外用一句话说明重要创作补充。用户说“只给提示词”时只给正文。不要再列五条长成品，也不要把内部简报与全部检查过程一起交给用户。

“生成”在本创意选择流程中表示展开提示词；实际出图需要用户明确要求生成图片，并使用环境里可用的出图能力。没有出图工具时仍完成提示词，不能假装已生成或展示图片。
