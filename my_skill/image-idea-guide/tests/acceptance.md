# 图片创意构思验收

在独立上下文读取技能及按需资源后，执行以下真实请求。检查实际创意内容、选择保留和衔接行为，不匹配固定文案。不调用出图工具。

| 编号 | 输入 | 可观察的预期行为 |
| --- | --- | --- |
| I01 | 我想生成一张可爱壁纸 | 首轮给多组完整画面，角色、场景或媒介有实质区别，考虑壁纸留白；不先问年龄发色，不直接只给一条长提示词 |
| I02 | 我想生成夏天的图片，还没想好画什么 | 包含乡野、城市、静物、海边或幻想等不同方向；至少一案主动给相关命名参考，如宫崎骏式手绘动画氛围与原创田野少年，不把构思说成原片真实镜头 |
| I03 | 将军应敌，给几个方案 | 给有区别的动作阶段、场景与媒介；可包含《三国演义》典故参考，区分演义与史实，不擅自把全部方案锁成同一将军或同一战役 |
| I04 | 就选B | 锁定B，按已展示主题、角色、场景和媒介展开提示词；不把A当作推荐而覆盖B，不重新发散第一轮选项 |
| I05 | 生成／都按推荐 | 在已有创意表的上下文中采用当轮明确推荐的编号并展开；不随机选另一套，不把沉默当提交 |
| I06 | 用A的场景、B的角色、C的画风 | 逐项合并，保持用户原有硬性要求；只调整相互冲突的空间或动作关系，不把三个完整场景硬拼在一起 |
| I07 | 不喜欢，再来5个，不要小动物 | 生成新方向，避开已排除的小动物；改变故事或世界设定，不只给旧方案换颜色 |
| I08 | 只给3个，都是3D猫咪壁纸 | 恰好3个，全部满足3D与猫咪；在动作、场景、构图等允许维度建立差异，不用换媒介和物种充数 |
| I09 | 想要宫崎骏风格的夏天，给多个选项 | 保留点名的风格参考，说明自然、光色、手绘背景或少年冒险等借鉴点；构思仍有区别，不要求每案照搬既有角色 |
| I10 | 我想做一张没有人物的夏天图片 | 所有候选保留无人要求，不强塞男孩或人物基础设定表 |
| I11 | 你决定，只给一条完整提示词：可爱壁纸 | 直接采用一套协调方案并给完整提示词，不强迫多轮选择或先出5个方案 |
| I12 | 已选方案，细化时同伴skill不可用 | 可独立交付创意简报和完整提示词，做必要的动作空间检查；不以未安装其他skill为由停住 |
| I13 | A，先不要写提示词，只告诉我这个方向还能怎么变化 | 保留A并给相关变化，不把选择编号机械当作立即生成指令 |
| I14 | 作为电脑桌面，要留图标位置，不要字，给几个创意 | 尊重横向用途与留白、无字要求；不默认9:16手机构图或塞入标语 |

## 结构检查

- name与文件夹一致，元数据可解析，本地资源链接有效。
- 前轮创意编号、推荐编号与后轮展开方案对应。
- 可单独使用；同伴skill衔接是增强，不是硬性依赖。
- 参考作品与原创构思标记清楚，不捏造出图稳定性或已经展示的图片。
